Las Hijas del Barro

App de producción · SEDECULTA · Valladolid / Uayma / Mérida

Para publicar la app aquí:

  1. Descarga el archivo hijas-del-barro.html que te compartieron.
  2. En este repo, sube ese archivo como index.html (reemplaza este archivo).
  3. Ve a Settings → Pages → Source: Deploy from a branch → main / (root).
  4. La URL pública será:
    https://erikazotz.github.io/hijas-del-barro/
